# Media Assets Directory

Store evaluation recordings, high-speed GIFs, and architecture visuals here.

### Recommended Files:
1. `dynamic_stage4_demo.gif` — 5–10s clip of TurtleBot3 evading dynamic obstacles in Gazebo Stage 4.
2. `polar_lidar_verification.gif` — Matplotlib polar scan visualization from `src/tools/visualize_scan.py`.
3. `lstm_vs_mlp_comparison.gif` — Side-by-side comparison illustrating LSTM obstacle memory vs MLP collision under occlusion.
4. `system_architecture.png` — High-resolution system block diagram (or use the built-in Mermaid diagram).

These paths are already pre-configured as placeholders in the root `README.md`. Simply drop your GIFs into this folder using the matching filenames!
